# Expense Tracker

A simple console-based expense tracker written in Python.

## Features

- Add expense entries
- View all expenses
- Search expenses by:
  - category
  - keyword in description
- Show:
  - total expenses
  - expenses by category
- Delete expenses by ID
- JSON file storage
- Automatic ID generation
- Date and time tracking

## Technologies

- Python 3
- JSON
- pathlib
- datetime

## Run

```bash
python main.py
```
